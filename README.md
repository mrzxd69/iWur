# Scheduler Bot

TypeScript Telegram Bot для моего колледжа


📆 **Комфортабельный** - Присылает расписание лично Вам

✅ **Open-source** - Открытый исходный код

⭐️ **Доступный всем** - Расписание также поступает к учителям


## Начало
Установка зависимостей
```bash [bun]
bun install
```

Запуск проект
```bash [npm]
bun run dev
```
